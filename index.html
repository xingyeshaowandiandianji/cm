CMP 及矿卡产业链

CMP（Cryptocurrency Mining Processor）是英伟达专为加密货币挖矿设计的显卡系列，与普通 GeForce 游戏卡不同，CMP 系列去掉了视频输出接口，专注于算力输出。

除了 CMP 系列，市面上还有大量基于游戏卡改造的矿卡，比如 P104、P102、P106 等型号。它们本质上还是 GP104 / GP102 / GP106 核心，只是被厂商重新设计为无显示输出的挖矿专用卡。

  • P106 —— 基于 GP106 核心，算力适中，功耗较低，常见于入门挖矿平台
  • P104 —— 基于 GP104 核心，算力更强，适合中端矿机
  • P102 —— 基于 GP102 核心，算力最高，属于矿卡里的高端型号
  • CMP 系列 —— 英伟达官方矿卡，覆盖 30HX / 40HX / 50HX / 90HX 等多个型号

产业链大致分为上游芯片设计、中游板卡制造、下游矿场与渠道流通。随着矿潮退去，大量矿卡流入二手市场，成为低成本算力与折腾玩家的选择。

驱动介绍

驱动是操作系统与显卡之间的桥梁，负责把系统指令翻译成 GPU 能理解的语言。一块显卡能不能发挥全部性能，驱动版本的选择非常关键。

对于 CMP、P104、P102、P106 这类矿卡，常见的驱动来源有三类：

  • 英伟达官方驱动：稳定性最好，兼容性最强，但部分矿卡型号需要改 INF
  • 厂商定制驱动：针对特定板卡做过适配，安装更省心
  • 社区修改驱动：由玩家或工作室维护，支持更多冷门型号

本站整理的矿卡驱动均来自 雨糖科技，版权归雨糖科技所有。安装前请确认显卡型号与系统版本，避免装错导致黑屏或无法进入系统。

如何使用

安装驱动前，建议先做好这几步准备工作：

  • 确认显卡型号：可通过 GPU-Z 或设备管理器查看
  • 确认系统版本：Windows 10 / 11，64 位还是 32 位
  • 卸载旧驱动：建议用 DDU 在安全模式下彻底清除
  • 关闭杀毒软件：避免安装过程中被拦截

安装步骤：

  • 下载对应型号的驱动安装包
  • 解压后右键以管理员身份运行安装程序
  • 选择"自定义安装"，勾选"执行清洁安装"
  • 等待安装完成，重启电脑
  • 打开 GPU-Z 或设备管理器，确认驱动已正常加载

如果安装失败或出现黑屏，可以进入安全模式重新卸载驱动，再换一个版本重试。

别问，问就是垃圾佬的胜利。E5+CMP 40HX，三角洲实战 100 帧，内存先爆了。

先说结论：这套玩意儿能玩，但没点折腾精神别碰。

我手里这套是 E5-2673 v3（关了超线程，全核 3.0），配 CMP 40HX。主板是闲鱼捡的 X99 魔改板，显卡没显示输出，得补电容、刷雨糖驱动，还得拿个亮机卡输出。这一套下来，加上内存硬盘电源，总共不到 800 块。

实测数据

打三角洲烽火地带，1080P 全低画质，FSR 性能档。

第一张图是跑了 20 分钟的：平均 104 帧，1% Low 65 帧。CPU 占用 69%，温度 57 度；显卡占用 55%，温度 70 度。显卡没跑满，CPU 也没跑满，说明瓶颈在别的地方。

图 1：跑了 20 分钟，平均 104 帧

第二张图是另一局大战场，平均 88 帧，1% Low 49 帧。这局 CPU 占用 56%，显卡 52%，都挺闲的，但帧率就是上不去。

图 2：另一局大战场，平均 88 帧

重点看第三张图，这才是这套配置的真相：看 GPU 那栏，显卡占用率 99%，显存占用 60%，显卡功耗 115W，热点温度干到 82 度了。但 CPU 才 42W，占用 62%。更离谱的是内存，占用率直接干到 93%！16G DDR3 被吃满，这是最大的短板。

图 3：显卡 99% 占用，内存 93% 被吃满

所以这套配置的真实情况是：显卡在拼命干活，CPU 在摸鱼，但 PCIe 1.1 x4 的破通道把数据卡住了，16G 内存又不够用。显卡有劲使不出，内存先爆了，帧率自然上不去。

折腾的坑，我踩过的，你们别踩

  1. PCIe 锁 1.1：别管你插哪条槽，这破板子最高就给你锁在 1.1 x4。想跑 3.0？做梦。你就算补了电容也白搭。
  2. CMP 40HX 没输出：这卡原厂没显示接口，必须补电容 + 刷雨糖驱动，还得配亮机卡。少一步你都进不去游戏。
  3. DDR3 内存掉通道：这板子插四根内存必卡 B7。老老实实插两根，16G 根本不够用，建议直接上 32G。
  4. BIOS 拉稀：你想调 PCIe 速率？找不到选项的。刷了鸡血也没用，通道速度是硬锁的。

优化方面，就一句话

打鸡血（关超线程 + 锁 3.1 + 降压 -45），刷雨糖驱动，关掉所有后台和自动更新。剩下的别折腾了，你折腾不过这块板子的物理限制。

最后给个实在建议

如果你只是想安安稳稳玩个游戏，别碰这套垃圾。直接花几百块买个 RX 580 或者 GTX 1660 Super，插上就能用，不用补电容、不用刷驱动、不用怕掉驱动。

你要是跟我一样，就喜欢花小钱办大事，享受折腾的过程，那这套配置能让你玩得很爽——但爽的是折腾的过程，不是帧率。
